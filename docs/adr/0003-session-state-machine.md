# 0003. 화면 흐름은 상태 머신으로 Core에 두고, WinForms는 그리기만 한다

- 상태: 채택
- 날짜: 2026-10-01

## 배경
키오스크 규칙(시간 초과 시 처음으로, 개인정보 지우기, 본인 확인 실패 잠금, 결제 중에는 끊지 않기)이
버튼 클릭 이벤트 안에 흩어지면 테스트하기 어렵고, 화면을 바꿀 때마다 규칙이 깨진다.

## 결정
- `KioskSession`이 화면 상태(Idle → Identify → Menu → Bills → Paying → Done)와 규칙을 가진다.
- 시간은 `IClock`으로 주입해 테스트에서 60초 경과, 날짜 변경을 바로 재현한다.
- WinForms(`MainForm`)와 콘솔(`interactive`)은 같은 `KioskSession`을 쓴다. 화면 코드에는 업무 규칙을 두지 않는다.
- 디자이너 파일 없이 코드로 화면을 만든다(리뷰·변경 이력 확인이 쉬움).

## 결과
- 화면 규칙을 단위 테스트 5개로 검증.
- 맥·리눅스에서도 콘솔로 같은 흐름을 시연할 수 있다. WinForms는 Windows에서만 실행된다.
